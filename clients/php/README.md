# SQL Anywhere contracts for PHP

The [storage contracts](../../docs/contracts/README.md) (a durable queue, a
KV cache with TTL and locks, pub/sub over an event log) as a typed PHP API on
PDO. The classes in `src/` are generated by `cargo xtask gen-contracts` from
the same documents as the Rust API, and CI fails when a document changes
without them, so the SQL here is always the contract's own.

```php
use SqlAnywhere\Contracts\{Cache, PubSub, Queue};

$db = new PDO('sqlite:/var/data/app.db');      // SQLite or SQL Anywhere: same file format
Queue::install($db);                           // once, like a migration

$id  = Queue::enqueue($db, 'mail', $payload, priority: 0, delay: 0, maxAttempts: 25)['id'];
$job = Queue::claim($db, visibility: 30, queue: 'mail');   // ['id' => …, 'payload' => …] or null
Queue::ack($db, $job['id']);

Cache::set($db, 'user:7', $json, expiresAt: time() + 300);
$lock = Cache::lock($db, 'import', owner: gethostname(), ttl: 60);   // null when someone else holds it

PubSub::publish($db, 'orders', $event);
foreach (PubSub::subscribe($db, 'orders', cursor: $last, batch: 100) as $e) { /* $e['seq'], $e['payload'] */ }
```

- One `final class` per contract: `install()`, `VERSION`, `SCHEMA`, the SQL of
  every operation as a constant, and one static method per operation taking
  `\PDO` and the operation's parameters, typed from the contract's parameter
  table (`int`, `string`, nullable where the contract says so).
- Rows come back as arrays keyed by column name. `:exec` operations return the
  number of rows changed, `:opt` ones `null` when there is no row, and `:one`
  ones throw when there is none.
- An operation of several statements (dead-lettering a job, invalidating a
  tag) runs them in one transaction, `BEGIN IMMEDIATE` where the contract says
  so, and rolls back if one fails. Call it outside a transaction of your own.
- Payloads are bound as blobs, so arbitrary bytes round-trip.

Requires PHP 8.1+ with `pdo_sqlite`. Tests: `php tests/contracts_test.php`
(no dependencies), run in CI by `.github/workflows/php-client.yml`.
